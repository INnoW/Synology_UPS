# 🚦 Network Sentinel Auto Shutdown

一个用于群晖 NAS 的网络连通性监测与自动关机脚本。

通过对局域网关键节点进行持续探测，在检测到核心链路同时中断（疑似断电）时，自动触发安全停机流程，避免设备在 UPS 电量耗尽前异常断电。

---

## 🧠 工作原理

脚本默认监测两个关键节点：

- `192.168.xx.xx`：主网关（Primary Gateway）
- `192.168.xx.xx`：边界网关（Edge Gateway）

判定逻辑如下：

- 任意一个节点可达 → 判定链路正常  
- 两个节点同时不可达 → 判定链路中断（疑似断电）  
- 连续两次检测均异常 → 执行安全关机  

👉 本质是：**双节点冗余判定 + 连续确认机制**

---

## ⚙️ 核心特性

- 双节点探测，避免单点误判  
- 连续异常确认，降低误触发概率  
- 自动执行群晖安全关机  
- 自动清理 30 天历史日志  
- 日志采用监控系统风格，便于排障分析  
- 轻量无依赖，适合长期运行  

---

## 🧩 配置说明

脚本关键变量：

```bash
ROUTER_IP_1="192.168.100.50"                 # 主网关
